# ADR-004: テンプレート素材（DodontoF 素材の取り込み）

- Status: Proposed
- Date: 2026-11-10
- 関連: [ADR-003](003-accounts-and-lobby-room-user.md)

## 背景
立ち絵・キャラクター画像・カードなどのテンプレート素材として、DodontoF に同梱されているものを使えるようにしたい。
一方、FortunaVTT は MIT ライセンスの OSS として公開する。

DodontoF 同梱素材の権利関係（DodontoF の README より）:
- DodontoF 本体は修正BSDライセンス。ただし同梱の画像・ライブラリは**それぞれのライセンスに従う**。
- キャラクター画像は外部素材サイト（First Seed Material 等）からの流用。
- 立ち絵は提供者の許諾が「どどんとふでの利用に限り」。
- `cards/` には商業TRPG（N◎VA、ブレイド・オブ・アルカナ、ガンメタルブレイズ等）のカードデータが多数含まれる。

これらを FortunaVTT のリポジトリにコピーして MIT で再配布するのは、権利上できない（または未確認）。

## 決定

### 1. 素材をリポジトリに同梱しない
DodontoF 由来の画像・音声・カードデータは、FortunaVTT のリポジトリにコミットしない。
`.gitignore` で取り込み先（`data/templates/`）を除外する（設定済み）。

### 2. 取り込みツールを提供する
`tools/Fortuna.Importer`（.NET CLI）で、**利用者が自分の DodontoF ディレクトリを指定して取り込む**。
- 入力: DodontoF のルート（`image/`、`cards/`、`imageUploadSpace/` 等）。
- 出力: `data/templates/` 配下に、素材ファイルと **マニフェスト**（JSON）を生成する。
- 取り込みは利用者（サーバー運営者）が自己責任で行う。ツールは出所と注意書きをマニフェストに記録する。

### 3. マニフェスト
各テンプレート素材に次を持たせる。
```json
{ "id": "...", "kind": "image|card|sound", "name": "...",
  "source": "dodontof", "origPath": "image/stand/glass_smile.png",
  "licenseNote": "どどんとふでの利用に限る（要確認）" }
```
出所不明・要確認のものは、UI でライセンス注意を表示できるようにする。

### 4. カードデータ
`cards/*.txt`（`title=...,(text|image)[,upDown]` 形式）のパーサーを Importer に実装し、
FortunaVTT のカードデッキ定義へ変換する。変換結果も `data/templates/` に置く（コミットしない）。

### 5. 同梱する素材は別途用意する
リポジトリに同梱する既定素材は、**CC0 / 自作 / 明確に再配布可能なもの**に限る。
同梱する場合は `ASSETS.md` に出典とライセンスを記録する。

### 6. 実行時の扱い
- テンプレート素材は全ルームから読み取り専用で参照でき、ルームに属さない（ルーム削除で消えない）。
- 配信は認証必須のエンドポイント経由（ADR-003 §5）。公開先は `Room` 相当（ログイン済みメンバー全員）。
- ルーム内で使う時は、参照を作るだけで、コピーはしない。

## 未決事項
- DodontoF 本体の作者が作成した素材（ダイス画像、アイコン類）は、修正BSDの条件下で同梱できる可能性がある。
  ただし各ファイルの作者を個別に確認できていないため、当面は取り込み対象とする。
- 取り込み時の重複排除（ハッシュ）とサムネイル生成。
- Importer の配布形態（`dotnet tool` か、サーバーに組み込む管理画面か）。

## 結果
- 利点: MIT の OSS としてクリーンに公開でき、利用者はテンプレートを使える。
- 欠点: 初回セットアップに取り込みの手間が必要。DodontoF を持っていない利用者には、素材が最初は空になる。

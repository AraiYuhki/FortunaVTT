# ADR-001: サーバー権威型の可視性モデルを採用する

- Status: Proposed
- Date: 2026-11-10

## 背景
どどんとふでは秘匿が機能していたが、Udonarium は全データを全員に配信するため秘匿できず、
TRPG運用上の不都合が生じた。新VTTの最重要要件は秘匿である。

## 決定
- 状態はサーバーのみが保持する（サーバー権威）。
- すべての配信は Visibility 層を通し、受信者ごとに「見えるもの」だけを送る。
- 見えないデータは存在自体を送らない（DevTools から覗かれても漏れない）。
- 後から見えるようになった場合は、その時点で配信する。

## 検討する論点（未決）
- 可視性の表現: 対象集合（ユーザー/ロール）か、ルールベースか。
- 秘密ダイスの結果と、公開後の扱い。
- 手札・山札・GM限定マップ領域・PL間の秘話チャットへの適用。
- 再接続時の状態再構築（受信者ごとのスナップショット）。
- 永続化はイベントソーシングか、現在状態のみか。

## 結果
- 利点: 秘匿をサーバーで保証できる。
- 欠点: サーバー実装が複雑になり、クライアント単独のオフライン動作はできない。
